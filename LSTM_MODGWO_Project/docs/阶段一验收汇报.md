## 3. 使用的数据与处理假设

- **来源：** Copenhagen Networks Study；官方 Figshare DOI `10.6084/m9.figshare.7267433`；本机实际下载 Netzschleuder CSV zip。
- **时间窗：** 1 天 = 86400 秒；共 **28** 个快照。
- **全局节点：** 跨层原始 `id` 并集 → MATLAB 1-based；`Network.V` 存原始参与者 ID；**N = 838**。
- **calls：** 有向；日权重 = 通话次数（含未接通事件，计 1）。
- **sms：** 有向；日权重 = 短信条数。
- **bt：** 原始无向；预处理为**双向等权弧**；日权重 = 扫描次数。
- **fb_friends：** 原始无向静态；双向弧；复制到各天仅便于时间对齐，角色为 static_ablation。
- **层间矩阵 C：** 暂置单位阵（同物理节点共享的占位）；阶段二需确认层间传播机制后再改。
