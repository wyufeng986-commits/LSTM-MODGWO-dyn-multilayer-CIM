# 阶段四实施说明

**启动日期：** 2026-11-27

## 目标

用 LSTM 预测竞争传播**剩余时间步**的双方规模 \((\hat\sigma_A,\hat\sigma_B)\)，为后续优化提供低成本近似 \(F_A\)。  
\(\mathrm{Cost}_{C4}\) 由种子集确定性计算，**不经 LSTM**。

## 设定

| 项 | 选择 |
|----|------|
| 序列粒度 | 每个网络快照一步（T=28） |
| 历史窗 r | 默认 8（可敏感性调整） |
| 预测 | 多步：\(t=r+1..T\) 的 \(\sigma_A,\sigma_B\) |
| 划分 | 按种子组合划分 train/val/test，防泄漏 |
| 主用层 | calls, sms, bt |

## 与优化衔接

短程真实仿真（前 r 步）→ LSTM 预测剩余 → 得近似 \(F_A\)；Cost 用 C4；入选解再做完整 MC 校正（阶段五）。
