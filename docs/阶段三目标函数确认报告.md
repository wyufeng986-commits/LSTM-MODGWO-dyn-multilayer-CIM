## 1. 定稿目标

\[
\max F_1(S_A)=F_A(S_A),\qquad
\min F_2(S_A)=\mathrm{Cost}_{C4}(S_A)
\]

约束：\(S_A\cap S_B=\varnothing\)，\(|S_A|=k\)。

**C4 混合成本（等权 \(\alpha=\beta=\gamma=1/3\)，各因子先 max 归一化）：**

- 加权出强度 \(s^{\mathrm{out}}\)
- 有效层数 \(L\)
- 活跃天数 \(D\)

\[
\mathrm{Cost}_{C4}(S_A)=\sum_{v\in S_A}\big(\alpha\hat s(v)+\beta\hat L(v)+\gamma\hat D(v)\big)
\]

**评价指标（不进主目标）：** \(F_B\)、层覆盖、HV/IGD 等。

详见 `docs/阶段三目标函数定稿.md`。

---

## 2. 为何不用 \((F_A,-F_B)\)

预实验（50 组随机 \(S_A\)）显示：

- Pearson\((F_A,F_B)\approx -0.9999\)
- \(F_A+F_B\approx 700\) 近似守恒
- 非支配解退化为 1 个

两目标高度协同，无实质 Pareto 权衡。

---

## 3. \((F_A,\mathrm{Cost}_{C4})\) 确认实验

| 项 | 值 |
|----|----|
| 样本数 | 60 |
| \(k_A,k_B\) | 5, 5 |
| R | 12 |
| \(\beta\) | 1.0 |
| 层 | calls, sms, bt |

| 指标 | 结果 |
|------|------|
| Pearson\((F_A,\mathrm{Cost})\) | **0.389** |
| Spearman\((F_A,\mathrm{Cost})\) | **0.468** |
| 非支配解 | **3 / 60** |
| 前沿 \(F_A\) 范围 | 55.5 ~ 368.8 |
| 前沿 Cost 范围 | 0.875 ~ 2.801 |

结论：影响力越高往往成本越高，前沿在两个目标上都有伸展，**双目标成立**。  
推荐：`accept_FA_CostC4`。
