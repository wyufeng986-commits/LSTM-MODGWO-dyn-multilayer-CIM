# 阶段三目标函数定稿

**确认日期：** 2026-11-27

## 双目标

\[
\max F_1(S_A)=F_A(S_A),\qquad
\min F_2(S_A)=\mathrm{Cost}_{C4}(S_A)
\]

约束：\(S_A\cap S_B=\varnothing\)，\(|S_A|=k\)。

## 成本 C4（混合部署成本）

对节点 \(v\)：

\[
\mathrm{Cost}(v)=
\alpha\,\hat s^{\mathrm{out}}(v)
+\beta\,\hat L(v)
+\gamma\,\hat D(v)
\]

其中（先按最大值归一化到 \([0,1]\)，再等权 \(\alpha=\beta=\gamma=1/3\)）：

- \(s^{\mathrm{out}}(v)\)：主用动态层上，各快照加权出强度之和  
- \(L(v)\)：有效层数（在该层至少有一条出边的层数）  
- \(D(v)\)：活跃天数（至少在一个主用层有出边的快照数）

\[
\mathrm{Cost}_{C4}(S_A)=\sum_{v\in S_A}\mathrm{Cost}(v)
\]

## 评价指标（不进主目标）

- \(F_B\)：对手最终传播规模  
- 层覆盖 / \(C_{\min}\)：可选补充  
- HV / IGD / Spread / Runtime：优化阶段使用
