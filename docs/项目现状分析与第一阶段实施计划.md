## 7. 关键模型差异（进入编码前必须对齐）

| 议题 | 已有实现 | 任务书要求 | 建议 |
|------|----------|------------|------|
| 传播范式 | CLTM 线性阈值 | 权重驱动 IC | **主模型用 IC**；可用 CLTM 作附录对照 |
| 竞争归属 | 双侧过阈后比输入；相等随机 | \(\rho_j = P^A/(P^A+P^B)\) | 阶段二先做规则对照实验，再定稿 |
| 层间机制 | 层权加权合并为有效网络 | 需显式定义共享状态或层间边 | **请确认**后再实现 |
| 动态性 | 静态多层，或时间切成层 | 快照序列上竞争传播 | 按任务书快照结构新建 |
| 优化编码 | 连续向量 Top-k / 单目标集合 | 离散集合三领导交换 | 新建 LSTM-MODGWO |
| 目标 | 第二部分常为传播 vs 成本等 | 首选 \((F_A,-F_B)\)，需预实验 | 阶段三预实验后确认 |
| 适应度 | 全量 MC | 短程真实 + LSTM + 校正 | 阶段四/五实现；论文终值必须真实 MC |

1. **系列论文序号冲突风险**：已有“有向加权”工程自称第三篇，与任务书第三部分可能撞车。

### 10.2 建议默认预处理约定（待确认）

- **calls：** 主叫 → 被叫有向；权重 = 窗口内通话次数（若有时长字段则另存原始并比较）。  
- **sms：** 发送 → 接收有向；权重 = 窗口内条数。  
- **bluetooth：** 接触无向原始关系 → 预处理为双向等权弧；论文明确“转换后有向”。  
- **facebook：** 默认作为静态层，不参与逐快照边演化；或单独做“是否纳入”消融。  
- **归一化：** 保留原始 `W`；传播用 \(\widetilde w\) 另存，避免覆盖原始权重。
