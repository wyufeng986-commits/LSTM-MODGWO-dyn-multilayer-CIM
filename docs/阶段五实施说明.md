# 阶段五实施说明：LSTM-MODGWO

**日期：** 2026-11-27  
**状态：** 烟雾测试已通过（见《阶段五MODGWO验证报告》）

## 目标

独立可跑的多目标离散灰狼：\(\max F_A,\ \min\mathrm{Cost}_{C4}\)，固定 \(k\)，\(S_A\cap S_B=\varnothing\)。

## 模块

| 文件 | 作用 |
|------|------|
| `repairSeedSet.m` | 合法化：去重、避让 \(S_B\)、补齐/截断到 \(k\) |
| `calculateNodePotential.m` | \(H(v)=s^{\mathrm{out}}/(Cost+\varepsilon)\) |
| `initializeWolves.m` | 潜力 / 随机 / 多样性混合初始化 |
| `discreteUpdate.m` | 三领导狼定向交换 + 多数投票 |
| `updateArchive.m` / `archive_utils.m` | 非支配档案 + 网格截断 |
| `selectLeaders.m` | 反密度轮盘选 α/β/δ |
| `localSearch.m` | 单点交换局部搜索 |
| `evaluateCandidate.m` | `mc` / `lstm` / `hybrid` 评价 |
| `LSTM_MODGWO.m` | 主循环 |
| `experimentMODGWO_smoke.m` | 烟雾实验入口 |

## 评价策略

- **Cost**：解析 \(\sum_v\mathrm{Cost}_{C4}(v)\)
- **F_A（优化内）**：短程真实 IC（前 \(r\) 快照）+ 残差 LSTM 终值
- **入档校正**：hybrid 周期 MC；结束时对档案强制高精度 MC

## 烟雾默认参数

`pop=10, iter=6, kA=kB=5, R_fast=3, R_final=8, archive=15, mode=hybrid`
