**本机不跑重实验。** 通过 GitHub 私有仓库在另一台机器克隆/拉取后执行。

仓库：`https://github.com/wyufeng986-commits/LSTM-MODGWO-dyn-multilayer-CIM`

```bash
git clone https://github.com/wyufeng986-commits/LSTM-MODGWO-dyn-multilayer-CIM.git
cd LSTM-MODGWO-dyn-multilayer-CIM/LSTM_MODGWO_Project
```

已有克隆时先 `git pull`。

## 2. 环境要求

- MATLAB R2021a+（开发机为 R2024a）
- **Deep Learning Toolbox**（`hybrid` / `lstm` 必需）
- 建议独立机器、可长时间运行；有 GPU 更好（无 GPU 也可用 CPU）

---

## 3. 预设参数

| preset | pop | iter | archive | R_fast / R_final | 模式 | 用途 |
|--------|-----|------|---------|------------------|------|------|
| `medium` | 20 | 20 | 40 | 4 / 20 | hybrid | **建议先跑**干跑 |
| `formal` | 50 | 50 | 100 | 5 / 50 | hybrid | 正式主实验 |
| `formal_mc` | 50 | 50 | 100 | 10 / 50 | mc | 无 LSTM 对照（更慢） |
| `smoke` | 8 | 4 | 15 | 2 / 5 | hybrid | 仅自检 |

默认 **\(k_A=k_B=5\)**，与当前残差 LSTM 训练设定一致。  
不要在未重训 LSTM 时把 \(k\) 改成 \(0.05N\)。

---

## 4. 怎么跑

### 方式 A（推荐）

1. 打开 `run_formal_modgwo.m`
2. 先把 `PRESET = 'medium';`，跑通后再改 `'formal'`
3. 在工程根目录执行该脚本

### 方式 B（命令行）

```bat
cd /d <拷贝后的>\LSTM_MODGWO_Project
matlab -batch "run_formal_modgwo"
```

或：

```matlab
cd('<拷贝后的>/LSTM_MODGWO_Project');
addpath(genpath('.'));
result = experimentMODGWO_formal('preset','medium');   % 先干跑
result = experimentMODGWO_formal('preset','formal');   % 再正式
```
